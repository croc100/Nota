# 검증용 자료

0단계 알고리즘 검증(`docs/ALGORITHM.md` 8절)에 필요한 자료를 여기에 둔다.
**이 디렉토리의 실제 파일은 git에 커밋하지 않는다** — 악보와 녹음은 저작권이
있고 용량이 크다.

## 필요한 것

### 악보 PDF (`scores/`)
시스템·마디선 검출(V1, V2) 검증용. 다양성이 중요하다:

- 조판 품질: 디지털 조판(MuseScore/Finale 출력), 고품질 스캔, 저품질 스캔, 사진 촬영
- 밀도: 느린 곡(시스템당 2~3마디)부터 빠른 곡(시스템당 6마디 이상)까지
- 시대/양식: 바로크(바흐 인벤션), 고전(소나타), 낭만(쇼팽 녹턴 — 루바토 많음),
  현대/팝 편곡
- 기울어진 스캔, 음영이 있는 스캔 (전처리 검증용)

권장 출처: IMSLP (퍼블릭 도메인), MuseScore 커뮤니티 악보

목표 20종.

### 연주 녹음 (`audio/`)
온셋·템포 추정(V3~V7) 검증용. 위 악보와 **짝이 맞아야** 한다.

- 페달 없는 연주 / 페달 적극 사용한 연주 (V3 vs V4 구분)
- 메트로놈에 맞춘 연주 (V5의 정답 템포 확보)
- 루바토가 있는 자연스러운 연주 (V6의 현실적 난이도)
- 중간에 멈추고 다시 시작하는 녹음 (V7)
- 녹음 환경: 조용한 방, 생활 소음이 있는 방, 어쿠스틱 피아노와 디지털 피아노

형식: WAV 44.1 kHz 이상, 모노 또는 스테레오.
iPhone 마이크로 녹음한 것도 반드시 포함할 것 — 실제 사용 조건과 가장 가깝다.

### 정답 데이터 (`labels/`)
- 온셋 시각 목록 (V3, V4의 F-measure 계산용)
- 마디 경계 좌표 (V2용)
- 정답 템포 (V5용)

MIDI 키보드로 녹음하면 온셋 정답을 자동으로 얻을 수 있다. 가장 효율적인 방법.
