# 검증용 자료

0단계 알고리즘 검증(`docs/ALGORITHM.md` 8절)에 필요한 자료를 여기에 둔다.
**이 디렉토리의 실제 파일은 git에 커밋하지 않는다** — 악보와 녹음은 저작권이
있고 용량이 크다.

## 필요한 것

### 악보 PDF (`scores/`)
시스템·마디선 검출(V1, V2) 검증용. 다양성이 중요하다:

- 조판 품질: 디지털 조판(MuseScore/Finale 출력), 고품질 스캔, 저품질 스캔, 사진 촬영
- 밀도: 느린 곡(시스템당 2~3마디)부터 빠른 곡(시스템당 6마디 이상)까지
- 시대/양식: 바로크(바흐 인벤션), 고전(소나타), 낭만(쇼팽 녹턴 — 루바토 많음),
  현대/팝 편곡
- 기울어진 스캔, 음영이 있는 스캔 (전처리 검증용)

권장 출처: IMSLP (퍼블릭 도메인), MuseScore 커뮤니티 악보

목표 20종.

### 연주 녹음 (`audio/`)
온셋·템포 추정(V3~V7) 검증용. 위 악보와 **짝이 맞아야** 한다.

- 페달 없는 연주 / 페달 적극 사용한 연주 (V3 vs V4 구분)
- 메트로놈에 맞춘 연주 (V5의 정답 템포 확보)
- 루바토가 있는 자연스러운 연주 (V6의 현실적 난이도)
- 중간에 멈추고 다시 시작하는 녹음 (V7)
- 녹음 환경: 조용한 방, 생활 소음이 있는 방, 어쿠스틱 피아노와 디지털 피아노

#### 녹음 형식 — 측정 결과 (2026-11-05)

압축이 온셋 검출에 얼마나 해로운지 실측했다. 합성 오디오(페달 최대)에
각 형식으로 인코딩한 뒤 F-measure를 쟀다.

| 형식 | F | 판정 |
|---|---|---|
| WAV 44.1 kHz | 0.990 | 좋음 |
| WAV 22.05 kHz | 0.995 | 좋음 |
| WAV 16 kHz | 0.989 | 좋음 |
| Opus 128 kbps | 0.997 | 좋음 |
| MP3 320 kbps | 0.993 | 좋음 |
| MP3 192 kbps | 0.994 | 좋음 |
| **MP3 128 kbps** | **0.838** | 나쁨 |
| MP3 96 kbps | 0.814 | 나쁨 |
| AAC 256 kbps | 0.915 | 주의 |
| AAC 128 kbps | 0.873 | 나쁨 |
| **AAC 64 kbps 모노 (휴대폰 음성메모 기본값)** | **0.775** | 매우 나쁨 |

읽는 법:

- **표본화 주파수는 거의 영향이 없다.** 16 kHz에서도 0.989다. 온셋은 광대역
  현상이고 저역이 그것을 충분히 싣는다. 용량을 줄여야 하면 비트레이트가
  아니라 표본화 주파수를 낮추는 편이 낫다.
- **코덱과 비트레이트가 결정적이다.** MP3는 192 kbps 이상이면 무해하지만
  128 kbps에서 0.99에서 0.84로 떨어진다. 저비트레이트 코덱이 버리는 것이
  정확히 트랜지언트이기 때문이다.
- **휴대폰 음성메모 기본 설정이 가장 위험하다.** 사용자가 가장 쉽게 녹음하는
  방식인데 F가 0.775다. iPhone 음성 메모는 설정에서 "무손실"로 바꿀 수 있다.
- AAC 결과는 ffmpeg 내장 인코더 기준이다. Apple 인코더는 더 낫다고 알려져
  있으므로 이 수치는 비관적일 수 있다.

**권장:** WAV(무손실) 우선, 어려우면 MP3 320 kbps. 128 kbps 이하와 음성메모
기본 설정은 피한다.

### 정답 데이터
### 정답 데이터 (`labels/`)
정답이 없으면 수치로 판정할 수 없다. 비용이 낮은 순서로 적는다.

**1. 정렬 기준점 (가장 싸고, 가장 중요하다)**

녹음을 들으며 몇 지점에서 "몇 분 몇 초에 몇 번째 마디" 를 적는다. 30초에
하나씩, 3분 녹음이면 예닐곱 개면 된다.

이것이 **V6(드리프트)** 를 직접 측정한다. 제품의 성패를 가르는 지표이고,
온셋을 일일이 라벨하는 것보다 수백 배 싸다. 스크롤이 연주자와 함께 가는가를
재는 것이 결국 이 값이다.

```
0:00  1마디
0:28  9마디
1:02  19마디
...
```

**2. MIDI 동시 녹음 (디지털 피아노가 있다면)**

오디오와 MIDI를 함께 녹음하면 온셋 정답이 공짜로 따라온다. V3·V4의
F-measure를 사람 손 없이 계산할 수 있다. 가능하다면 이것이 가장 가치 있다.

**3. 온셋 시각 목록**

MIDI가 없고 V3/V4를 정밀하게 재야 할 때만. 손으로 라벨하는 비용이 크므로
1번과 2번이 모두 불가능할 때의 마지막 수단이다.
